# Zeiteisen

> **Note:** This project was mostly generated by AI: code, configuration and
> documentation were written with [Claude Code](https://claude.com/claude-code).

PWA to try out group combinations for a personal university timetable. Runs
entirely in the browser: no backend, nothing is ever sent. Data lives in
local storage; the footer's "Data" menu saves and loads backups. On iPhone and
iPad add it to the home screen, Safari deletes site data after 7 days unused.

Vite + React 19 + TypeScript + Tailwind v4, `paraglide-js` (en/de), `zod/mini`.

## Development

```sh
npm run dev                 # dev server, serves srv/catalog/ at /catalog/
npm run build               # messages, typecheck, AI skill zip, build to dist/
npm test                    # vitest
npm run lint && npm run fmt # oxlint, oxfmt
npm run messages            # after editing messages/*.json
npm run schema              # JSON schemas (also :timetable :dates :locations :degree :catalog)
npm run catalog -- <dir>    # (re)write <dir>/index.json
npm run skill               # after editing skill/
npm run catalog-remote      # index ./catalog and copy it to the server
```

Code layout: `src/lib/primitives/` holds the domain model and core logic,
everything else builds on it. Every directory with its own logic has a
`NOTES.md` with the reasons behind it.

## Catalog (optional)

Static JSON files next to the app, so locations, subject names, semester dates
and ready-made timetables need not be collected by hand. Missing, broken or
offline: the app keeps working.

```text
catalog/
  index.json           # generated: npm run catalog -- <dir>
  locations.json       # building -> name, maps link, site link
  degrees/*.degree     # subjects of one degree programme (flat, e.g. B-EI.degree)
  dates.json           # semester dates
  timetables/**/*.json # timetables offered in the picker
```

Re-run `npm run catalog` after every change. Another origin works too
(`VITE_CATALOG_URL=https://…/catalog/ npm run build`, needs CORS).

## Deployment

A GitHub release builds `zeiteisen-<tag>.zip` and the image
`ghcr.io/ohmtools/zeiteisen` (`<tag>`, `1.2`, `latest`). Set the repository
variable `VITE_SITE_URL` (e.g. `https://zeiteisen.example.org`) for the link
preview images.

The image is just `dist/` and [static-web-server](https://static-web-server.net)
on port 8080, running as `nobody`. It sends all headers itself (CSP,
COOP/COEP/CORP, Permissions-Policy, caching, compression; see
`static-web-server.toml`), the proxy only adds TLS and HSTS.

Rootless Quadlet in `~/.config/containers/systemd/`, `zeiteisen.network`:

```ini
[Network]
```

`zeiteisen.container`:

```ini
[Container]
ContainerName=zeiteisen
Image=ghcr.io/ohmtools/zeiteisen:latest
AutoUpdate=registry
PublishPort=[::1]:8081:8080
# Own network; otherwise pasta's guest address is used, which can be confusing
Network=zeiteisen.network
Volume=%h/.local/share/zeiteisen/catalog:/public/catalog:ro

ReadOnly=true
NoNewPrivileges=true
DropCapability=ALL
User=65534
Group=65534

[Service]
Restart=always
MemoryMax=64M
# Compression runs on every request: a first visit costs ~30–70 ms CPU
CPUQuota=50%
TasksMax=32

[Install]
WantedBy=default.target
```

```sh
systemctl --user daemon-reload && systemctl --user start zeiteisen
systemctl --user enable --now podman-auto-update.timer  # daily updates
loginctl enable-linger zeiteisen                        # as root
```

Caddy:

```caddyfile
zeiteisen.example.org {
	header ?Strict-Transport-Security "max-age=63072000; includeSubDomains"
	reverse_proxy [::1]:8081
}
```

Keep the port on `[::1]`, the proxy is the only way in. The catalog
must be world-readable (the server runs as `nobody`). Roll back by
pinning a tag (`zeiteisen:1.2.9`). Private package: `podman login ghcr.io
--authfile ~/.config/containers/auth.json` with a `read:packages` token.

`npm run catalog-remote` uploads `./catalog` over ssh (overwrites, never
deletes). It reads from `.env.local`:

```sh
ZEITEISEN_SSH=ssh://root@example.org:2222
ZEITEISEN_CATALOG_DIR=.local/share/zeiteisen/catalog  # in the owner's home
ZEITEISEN_CATALOG_USER=zeiteisen
```
